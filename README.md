# Economic Insecurity and Justifiability of Norm Violations in Southeast Asia

HS4002/HS4902 Group Presentation #1
Team: Beagle
Members: Claire, Gabriel, Ryan, Xavier

## What this project is

We study whether economic insecurity is associated with how justifiable people
find economic norm violations (e.g. tax cheating, claiming unentitled benefits)
compared to personal norm violations (e.g. divorce, premarital sex), using World
Values Survey Wave 7 data for seven Southeast Asian countries: Myanmar, Indonesia,
Malaysia, the Philippines, Singapore, Vietnam, and Thailand.

## Data

Source: World Values Survey Wave 7 (2017-2022), v6.0.0
https://www.worldvaluessurvey.org/WVSDocumentationWV7.jsp



The trimmed extract (`data/raw/WVS_Survey_Trimmed.csv`) is in data, raw folder.
